# 身体与大脑通信协议 · 团队入口

此页为协作仓库重新整理的协议导航。字段、边界和编解码以 [协议实现](../../../src/companion/contracts/body.py) 与 [协议测试](../../../tests/contracts/test_body_protocol.py) 为准。

身体端主动通过 WSS 连接大脑端。配对使用双向 TLS 认证；开发者为自己的测试设备生成证书，不提交或共享私钥。

- 控制消息采用 JSON 文本帧，包含版本、类型和连续序号；握手建立新的会话。
- 身体端上报按键、静音、录音结束、播放结束和故障；大脑端发送录音、播放及表情指令。
- 音频采用单声道 PCM16LE，二进制帧具有 20 字节头；上行采样率为 16000 Hz。
- 会话断开后旧话轮与旧播放失效。心跳、发送期限、序号和背压由传输层及其测试约束。
- 表情只传递状态。真实静音开关、GPIO 按键与实体运动适配须另行验证，开发替代实现不代表硬件已经完成。

模块导航、无设备测试和部署工具见 [硬件入口](../../HARDWARE.md)。此文档不包含个人设备地址、证书或个人学习配置。
