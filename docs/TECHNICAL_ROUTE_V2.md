# RC-PEM 技术路线 v2 · 团队协作版

更新：2026-10-17。本页重新整理通用方法与工程状态，供团队开发和复现实验使用。个人原始资料、个人学习产物、私人案例的日期与数量、个人评分、关系分析结论和本机配置均不随本页分享。

## 研究目标

研究一套可替换目标用户授权历史的个人语言模仿方法。将语境理解、历史适配、回应焦点、回应策略、素材适用性和措辞生成分开验证，检验哪些模块有收益、何时应回退。

方法目标与已实现范围分别报告。实现一种算法、测试通过、某个案例有效，均不能替代未见用户上的验证，也不等于复制人格或得到被模仿者认可。

## 当前可运行路径

授权的外部学习材料 → 本地 BM25 片段检索与整体样例 → 可选习惯卡 / 专属表达 / 授权记忆与画像 → 提示构建 → 基础模型调用 → 输出处理。

仓库不提供真实运行所需的个人学习材料或凭据。队员可以用合成数据与 fake provider 验证完整软件流程；真实模型、数据、硬件实验须使用各自明确获准的资源。

代码还包含 `PersonalizationSpec` 编译与确定性风格验证路径。它与片段路径在 [装配处](../src/companion/dialogue/composition.py) 明确互斥，不能将两套实现合并描述为当前同时启用的功能。F/S/G 的离线研究工具也不等于在线链路已接通。

## 数据与评测约束

- 优先使用独立编造的合成数据，或已经确认允许相关用途的公共数据。公开可下载不自动意味着允许重分发或生成标注衍生物；候选数据由数据负责人逐项核验许可。
- 按说话人及关联事件隔离开发、校准、测试；近重复、相同前后文不能跨池。正式测试答案由独立验收人保管，开发人员不得反复针对封存题调参。
- 分别报告历史一致性、语境合适性、目标用户区分度。指标包括焦点命中/越界、策略 NLL/Brier、门控误用/漏用与 ECE、生成形态分布、延迟。
- 门控自动构造标签只作为弱标签，须有人工抽查和噪声分析；不能把模型自评分当成独立人工事实。
- 在等资源基线下逐层消融，允许没有收益的模块关闭；少量试题用于探索，不宣称普遍或统计显著提升。
- 私人案例及其学习成果由持有者单独维护。团队完成通用工具后，可以交持有者在私人环境中独立运行，仅返回获准共享的汇总结论。

## 应用工程边界

语音适配、表情状态、WSS 双向认证、身体客户端和会话隔离已有实现。GPIO 按键、实体静音开关、图形显示和实体运动适配可以单独分工；实际接线、驱动停止能力、断电与长时稳定性都需要各自的设备证据。

Mac 专用稳定性工具的原生测试仅在 Mac 执行；Linux 运行通用代码测试及不支持平台的拒绝测试。Windows 完整环境和实体设备未因 CI 配置而自动获得验证。
