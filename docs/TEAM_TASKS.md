# 可派发的团队任务

本页是任务候选与验收边界，不表示已经分配给某个人。每个工作包开始前，由负责人确认负责者、可写目录、数据来源、接口和验收命令；同一文件同一时间只安排一个写入者。

团队可以完成通用工程与公共/合成数据研究。个人学习结果、真实私人标注和最终私人效果验收继续由资料持有者完成。下列任务不要求队员读取负责人的原项目目录、使用其模型密钥或取得其私人样本。

## 第一批：可以立即开始

## 分工建议

- 对机器学习较熟的队员：先 T1/T7，再 T8/T9；不要一开始直接改整套对话主链。
- 对前后端和工具较熟的队员：T2/T3。
- 对嵌入式较熟的队员：T4/T5；真实器件与电气规格由负责人先确定。
- 对环境和测试较熟的队员：T6，以及后续独立验收。

T2/T3 的工作可能同时涉及片段和页面流程，T4/T5 可能同时涉及启动入口；这些文件需要单独排期，避免并行冲突。算法作者不独自裁决自己的封存测试表现。

## 交接要求

每个 PR 写明：完成的具体行为、修改文件、合成/公共数据来源、实际验证命令与原始结果、尚未完成的真机/模型/平台验证。未获数据授权、未拿到器件、需要新依赖或需要改变公共接口时，先给负责人最小方案，不绕过边界。

不要向队员分发负责人的真实聊天、已完成个人学习成果、私人评分答案、私有运行配置或密钥。队员完成通用工具后，由资料持有者在私人环境中运行；回传信息也要单独审核。
